Subscribe Live VOD & MP4 Clip

Watch a live stream over WebRTC with DVR seek-back. Drag or click back on the timeline to play the HLS recording from that point; press LIVE (or seek to the end) to switch back to real-time WebRTC playback at around 200 ms latency. Set a start and end time on the player to create an MP4 clip of the HLS recording. Requires Stream Manager: provide the HLS playlist as a base or full URL (S3, CDN), or use the Stream Manager proxy for packager file output, before starting subscribe.

MP4 Clip

Seek the player to where the clip should begin and press Set Start Time, then seek to where it should end and press Set End Time. At live, the time set is the live edge. The video packager cuts the range into an MP4 without re-encoding (up to 3 hours). The HLS playlist must still list the range, so use hls.playlist.type=event or a long playlist. Clips go to S3 with S3 output, or next to the stream's HLS through the Stream Manager proxy with file output.
